Requesting Access

How to sign in for the first time, and which group to ask for.
Before you start

You need an Active Directory group, not an app account

There's no separate username or password for STO Management — access is controlled entirely through Active Directory group membership. Once you're in the right group, signing in with your normal company credentials just works.

How to request — in ServiceNow
  1. Go to Service Catalog → Accounts, Access & Authentication → Modify Active Directory Group Membership
  2. Active Directory Item: Security Groups
  3. Action Type: Add Account(s)
  4. Account type: Regular User Accounts
  5. Group List: search app-{site}-sto and pick the exact group from the table on the next page

Groups are per site

Every group below applies to one site — ABC, ABL, ABS, MBM, etc. If your job touches more than one site, submit the request above once per site — you can hold more than one group at a time.

What each group can do

Most common

Basic access — APP-{SITE}-STO_Management_Site

Create new STO requests and view requests for your site. Cannot approve, reject, or edit anything once a request moves past your own draft. This is the right group if you just need to submit requests and check their status — most people who aren't part of Planning, Logistics, or Management fall here.

Group suffixWhat it's for
_Planning Reviews new requests first; can approve, send back for revision, or reject.
_Logistics Adds freight and shipping details after Planning approves; routes the request onward.
_Management Shipping-site sign-off — only required for high-value, cold-chain, controlled, or otherwise flagged shipments.
_Management_Receiving Same as above, but the receiving-site sign-off. A distinct group — one doesn't grant the other.
_Logistics_Receiving Confirms receipt at the destination site and closes out the delivery.
_Site Basic access — create and view only, no approvals at any stage. See above.

Every group name follows the same pattern: APP-{SITE}-STO_Management_{suffix} — e.g. APP-ABC-STO_Management_Planning for Planning at site ABC.

Company-wide admin
There's also a single company-wide APP-STO_MANAGEMENT_ADMIN group, not tied to any one site — reserved for app administrators, not requested for day-to-day use.
